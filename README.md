## Description

This repository contains the R code necessary to **fully reproduce** the statistical analysis and figures presented in:

> "Post-Intensive Care Syndrome (PICS) in adult survivors: A systematic review and meta-analysis of assessment tools, risk factors, and long-term outcomes"

**Submitted to:** Scientific Reports

### Main Files

- **`scripts/01_meta_analysis.R`** - R script with detailed comments implementing:
  - Data reading and validation
  - Random-effects meta-analysis (DerSimonian-Laird)
  - Heterogeneity calculation (I², τ²)
  - Sensitivity analyses
  - Forest plot generation
  - Results table export

- **`data/meta_analysis_data.csv`** - Reproducible dataset with:
  - 77 rows: 22 studies × 10 domains
  - Variables normalized according to Methods specifications
  - Data quality documentation and outlier flagging

## Statistical Methods

**Random-Effects Meta-Analysis**
- Estimator: DerSimonian-Laird
- Heterogeneity: τ², I² statistics, Cochran's Q test
- Confidence intervals: 95% (pivot method)
- Sensitivity analysis: exclusion of outliers and low-N studies

**Measure Conversion**
- Median to mean: Wan et al. method (2014)
- Variance: approximation SD = (Q3 - Q1) / 1.35

**Data Quality Issues Resolved**
- Cognition domain: Not pooled (incompatible MoCA/MMSE scales)
- Barthel Index: Yamamoto excluded (outlier 50±50 vs. 96-100)
- Ventilation days: Milton excluded (units error detected)
